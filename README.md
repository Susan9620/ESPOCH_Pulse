# ESPOCH Pulse

ESPOCH Pulse será una prueba de concepto de Smart Campus para la ESPOCH. El GIS será el núcleo de integración de información del campus. Se utilizarán datos geográficos reales y datos simulados para la demostración.

Más adelante se trabajará con HTML, CSS, JavaScript, Leaflet, OpenStreetMap, GeoJSON y QGIS. El proyecto se desarrollará por etapas.
